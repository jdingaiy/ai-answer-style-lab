# ai-answer-style-lab

界面仅保留必要操作：场景选择移至顶部左侧，删除品牌区、参数区标题及回答预览内的品牌标签。

`<highlight>高亮强调</highlight>` 使用浅紫色整块底色、继承字重；`<mark>这是标记内容</mark>` 使用加粗文字与底部紫色标记（高度 0.5em），均支持换行及独立颜色设置。旧版 Mark 的整块底色自动迁移到新的标记样式，其他排版数值和 Markdown 保留。

mock 并优化 AI 回答的 Markdown 格式。

纯静态工具，无构建依赖、无 AI API 调用。编辑内容和三套参数仅保存在当前浏览器，不上传文本。

## 功能

- Web AI 搜索、App AI 搜索、App 搜索卡片三套独立参数。
- 正文、H1–H6、列表、引用、代码、表格正文与表头的字体、字号、字重、颜色。
- 所有文字行高支持 px / 倍数输入，切换时按当前字号等效换算；倍数模式在字号变化后随之变化。
- 正文、标题、有序／无序列表、引用、代码、表格、分割线统一提供段前与段后。
- 一键将有序列表的段前／段后同步到引用、代码、表格。
- 表格单元格内边距、分割线粗细与颜色可调。
- 宽表格可在容器内左右滑动；列内容最小宽度默认 80px，最大宽度 Web 为 280px、App 为 240px、卡片为 200px，均可调整。短内容按需占宽，长文本到达上限后换行。支持触屏、触控板和聚焦后的键盘滚动，导出的 CSS 使用同一规则。
- 可选父子标题紧凑排列；实时 Markdown 预览、元素边界辅助线与 CSS 导出。
- 打开“显示间距”后，在实际间隙中央显示测量值及生效设置（例如 H3 段前、正文段后、父子标题间距）；相等时同时标注两者。包含分割线两侧和列表项间距，修改参数或改变视口后实时更新。标注仅用于调试，不进入导出的 CSS。
- 支持 `<mark>高亮 **加粗** 内容</mark>`，高亮背景和文字颜色按场景独立调整。
- Markdown 编辑区下方提供实时 CSS 样式预览；参数、场景和重置操作同步更新，可一键复制或导出。
- 顶部版本管理可把 Web、App、搜索卡片三套参数和当前 Markdown 一起保存为版本，并在下拉菜单中切换或删除；最多保留 30 个版本。
- 点击“分享版本”会复制一个自包含链接，链接包含三端参数和 Markdown，别人打开后即可还原该调试版本；分享不会修改对方本地已有版本。

## 间距约定

相邻块间距 = max(上一块段后, 下一块段前)，不相加。容器首尾不额外留空。段前／段后指元素盒之间的距离，不包含行框内留白。

开启「父子标题紧凑排列」后，连续父→子标题使用独立的紧凑间距，优先于这两个标题的段前／段后；正文→标题等其他关系不受影响。分割线上下仍分别参与 max 计算。

列表项间距与列表整体段前／段后独立；嵌套列表、引用内部保持正常块结构。表格整体外间距与单元格内间距分开。

导出的 CSS 作用于 `.markdown-body`。Markdown 表格外需有 `.md-table` 容器，与本工具的渲染器一致。

## 更新与已有参数

更新沿用同一个网址与浏览器存储键 `ai-answer-style-lab-v1`，不会主动清空已保存的 Markdown、三套场景参数或版本列表。旧配置没有的 Mark 字段会自动补充默认值。版本保存在当前浏览器本地，不会上传服务器；清除网站数据、无痕窗口、换浏览器或换域名不会共享这份本地设置。

## 本地运行

需要 Python 3：

```sh
python3 -m http.server 4173 --directory dist
```

打开 http://localhost:4173 。不要直接双击 HTML：浏览器可能阻止本地 ES module 加载。

## 验证

需要 Node.js 20 或以上，不需要 npm install：

```sh
npm test
npm run check
```

## 部署

将 `dist/` 作为静态站点发布目录；所有资源均使用相对路径。可以部署到支持静态目录的托管服务。GitHub 仓库不等于已启用 GitHub Pages。

## 支持范围与安全

使用本地 vendored Marked 解析 GFM：标题、段落、列表／嵌套列表、任务列表、引用、表格、分割线、代码和链接。Marked 的 MIT 许可证位于 `dist/vendor/MARKED-LICENSE.md`。

原始 HTML 仅放行 `mark` 和 `highlight` 标签，并移除其全部属性；其他 HTML 转义显示。代码块和行内代码中的标签仍保留为代码。链接仅允许 HTTP(S)、mailto 或页内锚点；图片仅渲染为链接，避免载入外部图片。数学公式、Mermaid 图与知乎专有引用组件尚未接入。

初始基础值参考对话中的 Zhida Markdown 规范。分割线间距和未接入的低级标题使用显式 mock 值，不代表线上实现。参考站 `md-test.myagents.io` 未能读取，因此当前版本实现已明确的调试功能，外观尚未与参考站逐项核对。

表格单元格内容由 `.md-cell` 包裹，在普通块盒上限制宽度；完整结构是 `.markdown-body > .md-table > table`，每个 th/td 内有 `.md-cell`。不再强制表格填满容器，以免把短列拉宽。宽度参数不含单元格两侧 padding。

`.markdown-body` 和 `.answer` 都只是 CSS 类选择器，没有内建的渲染能力。当前版本统一使用 `.markdown-body`；旧 `.answer` 样式如需复用应统一替换类名，或明确使用双类名容器并处理层叠冲突。
